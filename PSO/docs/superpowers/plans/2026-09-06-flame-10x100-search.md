# FLAME 10x100 Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a bounded 10-particle, 100-iteration molecular search using local FLAME/FLSF predictions in dichloromethane and per-particle candidate inheritance.

**Architecture:** Keep TDDFT contracts untouched. Add a strict no-shell FLAME command backend that validates four checkpoint hashes and returns `FlamePrediction`; add a task-owned edit-then-FLAME workflow and adapter; add separate FLAME preflight/search CLI commands with an exact 1000-evaluation confirmation. Launch only after a real DiKTa four-model preflight succeeds.

**Tech Stack:** Python 3.12, Pydantic v2, asyncio, SQLite, Codex SDK, MoleculeEditor, FLAME/FLSF, PyTorch.
